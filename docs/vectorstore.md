# 🔍 HybridVectorStore Documentation (LangChain Integration)

The `HybridVectorStore` module (`mariadb_ai_toolkit.vectorstore`) is the core LangChain component. It enables **True Hybrid Search** by combining semantic similarity and structured filtering in a single, highly efficient query within MariaDB.

---

## 💡 MariaDB Feature Showcase: Hybrid Search

Hybrid search is critical for production RAG systems. This module solves the problem of needing **both** conceptual relevance and precise, structured filtering.

| Component | MariaDB Feature | Purpose |
| :--- | :--- | :--- |
| **Semantic Ranking** | `VEC_DISTANCE_COSINE()` | Ranks documents based on conceptual similarity to the query vector. |
| **Structured Filtering** | `JSON_VALUE()` | Filters documents based on exact matches within the `metadata` JSON column (e.g., stops = 0). |

By leveraging MariaDB's **unified data platform**, we execute both ranking and filtering in one SQL statement, ensuring speed and accuracy.

---

## 📝 Class: `HybridVectorStore`

This class extends the **`langchain_core.vectorstores.VectorStore`**, making MariaDB plug-and-play with RAG and AI workflows.

### Core Method: `similarity_search()`

This method accepts the standard LangChain `query` and enhances it with an optional `filter` dictionary to achieve hybrid results.

```python
from mariadb_ai_toolkit.vectorstore import HybridVectorStore

vector_store = HybridVectorStore(
    connection_details=DB_CONNECTION_DETAILS,
    table_name="flight_routes"
)

# Hybrid Query: Find semantically similar flights (quick to California)
# BUT ONLY for direct flights (stops=0) originating at JFK.
results = vector_store.similarity_search(
    query="a quick flight to California",
    k=5,
    filter={"stops": 0, "source_airport": "JFK"}
)

print(f"Retrieved {len(results)} relevant documents.")
for doc in results:
    print(f"- Text: {doc.page_content}")
    print(f"  Metadata: {doc.metadata}")
````

**Expected Console Output:**

```
Retrieved [N] relevant documents.
- Text: United Airlines cross-country trip to New York
  Metadata: {'source_airport': 'JFK', 'stops': 0}
- Text: British Airways transatlantic flight to the UK
  Metadata: {'source_airport': 'JFK', 'stops': 0}
...
```

*(Note: Actual text will vary based on semantic similarity ranking and exact data.)*

## ⚙️ Example Hybrid SQL Query

This is the key query pattern generated by the Python code to achieve hybrid search:

```sql
SELECT text_data, metadata
FROM flight_routes
-- Structured Filters (WHERE clause for precision)
WHERE JSON_VALUE(metadata, '$.stops') = '0' AND JSON_VALUE(metadata, '$.source_airport') = 'JFK'
-- Semantic Ranking (ORDER BY for relevance)
ORDER BY VEC_DISTANCE_COSINE(embedding, <query_vector>)
LIMIT 5;
```
